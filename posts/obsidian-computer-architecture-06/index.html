写回策略的组合解析

2025-11-17 updated 2025-11-17 7 min
  • 核心概念定义
  • 四种策略的行为解析
  • 重点解析：为什么 1(全写) 和 4(非写分配) 通常合用？为什么 2(写回) 和 3(写分配) 通常合用？
  • 总结

核心概念定义

  1. 写命中： CPU 要写入的数据地址正好在缓存中找到（缓存命中）。
  2. 写未命中： CPU 要写入的数据地址不在缓存中（缓存未命中）。
  3. 数据块/行： 缓存和主存之间数据传输的基本单位。缓存是按块/行组织的。

四种策略的行为解析

策略写命中时的行为写未命中时的行为
1. 全写法同时写入缓存中的对应块和主存中的对应位置。
2. 写回法只写入缓存中的对应块。将该块标记为“脏”（表示与主存内容不一致）。不立即写回主存。
3. 写分配法加载主存块到缓存，然后更新缓存块。
4. 非写分配法直接写入主存，不加载到缓存。

重点解析：为什么 1(全写) 和 4(非写分配) 通常合用？为什么 2(写回) 和 3(写分配) 通常合用？

这种组合主要是为了逻辑一致性和性能优化，避免冗余操作和浪费。

  1. 全写法 + 非写分配法 (Write-Through + No-Write-Allocate)

    • 逻辑一致性：
      • 全写法 的核心思想是：任何写操作（无论命中与否）都必须立即或最终反映到主存上，以保证缓存和主存数据的高度一致性。写命中时立即写入主存保证了这点。
      • 如果写未命中时采用 写分配法（即先加载主存块到缓存，再更新缓存块），那么：
        • 加载这个块到缓存后，你紧接着会根据全写法的规则，在更新缓存的同时又立即把刚更新的数据写回主存。
        • 这个“加载”操作是多余的！因为你最终的目的只是更新主存中的那个字（word/byte），而全写法要求你直接写主存就能实现这个目的。加载整个块（可能包含很多你不关心的数据）进来只是为了写其中一个字然后又立刻把它写回去，浪费了时间和宝贵的缓存空间、总线带宽。
    • 性能优化：
      • 非写分配法 在写未命中时直接写主存，避免了加载无用数据块的开销（内存访问延迟、占用缓存行、占用总线带宽）。对于一次性的写入或者后续不会立即读取的写入，这通常是更高效的做法。
      • 全写法本身每次写命中都写主存，开销已经很大。非写分配法避免了在写未命中时引入额外的、通常不必要的加载开销。
    • 总结： 全写法强制保持主存最新，非写分配法在未命中时直接更新主存而不引入缓存加载，两者配合避免了冗余操作（加载无用块+立即写回），逻辑清晰一致，减少了不必要的缓存污染和总线流量。适用于写操作相对不频繁或对一致性要求极高的场景（如共享内存系统）。

  2. 写回法 + 写分配法 (Write-Back + Write-Allocate)

    • 逻辑一致性 & 利用局部性：
      • 写回法 的核心思想是：推迟写回主存，只在必要时（如缓存块被替换且为脏）才写回。这大大减少了总线流量和访问主存的次数，利用了程序的空间局部性（一个块内的数据可能被多次读写）。
      • 如果写未命中时采用 非写分配法（即直接写主存）：
        • 你只是更新了主存中的那个字。但该地址所在的整个数据块仍然不在缓存中。
        • 如果 CPU 紧接着要读取或写入同一块内的其他地址（空间局部性），它会再次发生缓存未命中！需要再次访问主存加载整个块。这导致了额外的、可能完全可避免的缓存未命中。
      • 写分配法 在写未命中时，将整个数据块加载到缓存，然后更新目标字（并标记为脏）。这样：
        • 后续对该块内任何地址的读或写操作都将在缓存中命中，速度极快。
        • 利用了空间局部性，一次加载服务多次访问。
        • 推迟写回的特性得到了充分发挥：该块后续的多次写操作都只发生在缓存中（标记脏），直到被替换时才需要一次写回主存。
    • 性能优化：
      • 写分配法 在未命中时加载块，虽然有一次加载开销，但为后续可能的多次访问（尤其是写）创造了缓存命中的机会，显著减少了总的内存访问延迟和总线流量。
      • 写回法的延迟写回特性与写分配法加载后多次命中的优势完美契合，共同实现了最小化主存访问次数的目标。
      • 避免了非写分配法可能导致的“写后立即读/写同一块”的额外未命中惩罚。
    • 总结： 写回法利用延迟写回减少主存访问，写分配法在未命中时加载块以利用空间局部性并为后续访问（特别是写）服务。两者配合最大化缓存命中率，最小化总线流量和主存访问次数。适用于写操作频繁或对带宽敏感的场景（现代通用处理器缓存的主流选择）。

总结

  • 全写法 (WT) + 非写分配法 (NWA)： 追求强一致性，避免写未命中时引入无用的缓存加载开销。逻辑：写操作的目标是更新主存，直接做就好。
  • 写回法 (WB) + 写分配法 (WA)： 追求高性能和低带宽消耗，利用空间局部性。逻辑：写未命中时把整个块拿进来，后续访问很可能命中，多次写操作只需一次最终写回。
