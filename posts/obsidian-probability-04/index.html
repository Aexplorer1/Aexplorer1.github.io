事件A与B独立的条件总结

1. 基本定义

设 A,BA, BA,B 为两个随机事件，称 AAA 与 BBB 相互独立，如果满足： P(AB)=P(A)P(B)P(AB) = P(A)P(B)P(AB)=P(A)P(B)

2. 等价条件（设 0<P(A)<1,0<P(B)<10 < P(A) < 1, 0 < P(B) < 10<P(A)<1,0<P(B)<1）

  1. 条件概率形式（要求分母概率非零）：

    • P(A∣B)=P(A)P(A|B) = P(A)P(A∣B)=P(A)
    • P(B∣A)=P(B)P(B|A) = P(B)P(B∣A)=P(B)

  2. 条件概率相等：

    • P(A∣B)=P(A∣B‾)P(A|B) = P(A|\overline{B})P(A∣B)=P(A∣B)
    • P(B∣A)=P(B∣A‾)P(B|A) = P(B|\overline{A})P(B∣A)=P(B∣A)

  3. 条件概率组合形式（如例题27）：

    • P(A∣B)+P(A‾∣B‾)=1P(A|B) + P(\overline{A}|\overline{B}) = 1P(A∣B)+P(A∣B)=1
      （因为 P(A‾∣B‾)=1−P(A∣B‾)P(\overline{A}|\overline{B}) = 1 - P(A|\overline{B})P(A∣B)=1−P(A∣B)，可推出 P(A∣B)=P(A∣B‾)P(A|B) = P(A|\overline{B})P(A∣B)=P(A∣B)）

  4. 事件运算概率形式：

    • P(A∪B)=P(A)+P(B)−P(A)P(B)P(A \cup B) = P(A) + P(B) - P(A)P(B)P(A∪B)=P(A)+P(B)−P(A)P(B)
    • P(A∪B)=1−P(A‾)P(B‾)P(A \cup B) = 1 - P(\overline{A})P(\overline{B})P(A∪B)=1−P(A)P(B)
    • P(A−B)=P(A)P(B‾)P(A - B) = P(A)P(\overline{B})P(A−B)=P(A)P(B)（其中 A−B=AB‾A-B = A\overline{B}A−B=AB）
    • P(A△B)=P(A)+P(B)−2P(A)P(B)P(A \triangle B) = P(A) + P(B) - 2P(A)P(B)P(A△B)=P(A)+P(B)−2P(A)P(B)（对称差）

3. 独立性的继承性

若 AAA 与 BBB 独立，则以下每一对事件也相互独立：

  • AAA 与 B‾\overline{B}B
  • A‾\overline{A}A 与 BBB
  • A‾\overline{A}A 与 B‾\overline{B}B

即独立性在取补运算下保持不变。

4. 多个事件的独立性

(1) 两两独立

事件 A,B,CA, B, CA,B,C 两两独立是指：

P(AB)=P(A)P(B),P(BC)=P(B)P(C),P(AC)=P(A)P(C).\begin{aligned} P(AB) &= P(A)P(B), \\ P(BC) &= P(B)P(C), \\ P(AC) &= P(A)P(C). \end{aligned}P(AB)P(BC)P(AC)​=P(A)P(B),=P(B)P(C),=P(A)P(C).​

(2) 相互独立

事件 A,B,CA, B, CA,B,C 相互独立是指它们两两独立，并且同时满足： P(ABC)=P(A)P(B)P(C).P(ABC) = P(A)P(B)P(C).P(ABC)=P(A)P(B)P(C).

注意：两两独立不一定推出相互独立。相互独立是更强的条件。

5. 特殊情形

  1. 概率为 0 或 1 的事件：

    • 若 P(A)=0P(A)=0P(A)=0 或 P(A)=1P(A)=1P(A)=1，则 AAA 与任意事件 BBB 独立。
    • 特别地，P(A)=1⇒P(AB)=P(B)=P(A)P(B)P(A)=1 \Rightarrow P(AB)=P(B)=P(A)P(B)P(A)=1⇒P(AB)=P(B)=P(A)P(B)；
      P(A)=0⇒P(AB)=0=P(A)P(B)P(A)=0 \Rightarrow P(AB)=0=P(A)P(B)P(A)=0⇒P(AB)=0=P(A)P(B)。

  2. 包含关系下的独立：

    • 若 A⊆BA \subseteq BA⊆B，则 AAA 与 BBB 独立的充要条件是 P(A)=0P(A)=0P(A)=0 或 P(B)=1P(B)=1P(B)=1。

  3. 互斥事件与独立：

    • 若 AAA 与 BBB 互斥（即 AB=∅AB=\varnothingAB=∅），则 AAA 与 BBB 独立的充要条件是 P(A)=0P(A)=0P(A)=0 或 P(B)=0P(B)=0P(B)=0。
    • 当 P(A)>0P(A)>0P(A)>0 且 P(B)>0P(B)>0P(B)>0 时，互斥一定不独立。

  4. 对立事件与独立：

    • 对立事件（A∪B=ΩA\cup B=\OmegaA∪B=Ω 且 AB=∅AB=\varnothingAB=∅）在 P(A)>0,P(B)>0P(A)>0, P(B)>0P(A)>0,P(B)>0 时不独立，除非 P(A)P(A)P(A) 或 P(B)P(B)P(B) 为 0 或 1。

6. 常见题型与解题思路

  1. 验证独立性：首选定义 P(AB)=P(A)P(B)P(AB)=P(A)P(B)P(AB)=P(A)P(B)，或使用条件概率等价形式。
  2. 利用独立性简化计算：若 A,BA,BA,B 独立，则 P(A∪B)=P(A)+P(B)−P(A)P(B)P(A\cup B)=P(A)+P(B)-P(A)P(B)P(A∪B)=P(A)+P(B)−P(A)P(B)，P(A‾B‾)=P(A‾)P(B‾)P(\overline{A}\overline{B})=P(\overline{A})P(\overline{B})P(AB)=P(A)P(B) 等。
  3. 识别题干中的隐蔽条件：如 P(A∣B)+P(A‾∣B‾)=1P(A|B)+P(\overline{A}|\overline{B})=1P(A∣B)+P(A∣B)=1 往往提示 P(A∣B)=P(A∣B‾)P(A|B)=P(A|\overline{B})P(A∣B)=P(A∣B)，进而可能推出独立。
  4. 注意区分：
    • 互斥：AB=∅AB=\varnothingAB=∅，即 P(AB)=0P(AB)=0P(AB)=0。
    • 独立：概率乘积关系，无交运算限制。
    • 互斥与独立一般不能同时成立（除非概率为 0）。

7. 例题

例题27：已知 0<P(A)<1,0<P(B)<10<P(A)<1, 0<P(B)<10<P(A)<1,0<P(B)<1，且 P(A∣B)+P(A‾∣B‾)=1P(A|B)+P(\overline{A}|\overline{B})=1P(A∣B)+P(A∣B)=1，证明 AAA 与 BBB 相互独立。

推导： 由 P(A‾∣B‾)=1−P(A∣B‾)P(\overline{A}|\overline{B}) = 1 - P(A|\overline{B})P(A∣B)=1−P(A∣B)，代入条件得： P(A∣B)+1−P(A∣B‾)=1⇒P(A∣B)=P(A∣B‾).P(A|B) + 1 - P(A|\overline{B}) = 1 \Rightarrow P(A|B) = P(A|\overline{B}).P(A∣B)+1−P(A∣B)=1⇒P(A∣B)=P(A∣B). 从而 P(A∣B)=P(A∣B‾)P(A|B) = P(A|\overline{B})P(A∣B)=P(A∣B)，结合 P(A)=P(A∣B)P(B)+P(A∣B‾)P(B‾)P(A) = P(A|B)P(B) + P(A|\overline{B})P(\overline{B})P(A)=P(A∣B)P(B)+P(A∣B)P(B)，可得 P(A∣B)=P(A)P(A|B)=P(A)P(A∣B)=P(A)，故 AAA 与 BBB 独立。

记忆要点：独立性核心是“概率乘法”，条件概率“无影响”，以及补运算下的保持性。掌握等价条件，注意特殊概率值（0 或 1）带来的结论。
